## 学习原则

1. **输入与输出时间比 1:2** —— 看 10 分钟就敲 20 分钟。
2. **每篇笔记必须有"我原来以为…实际上…"的认知修正**，否则说明只是在抄书。
3. **记录时间不超过学习时间的 20%** —— 笔记是副产品，不是主线。
4. **不提交任何实验室私有数据、未发表方法或受保密约束的内容。** 本仓库为公开仓库，医学数据一律不入库。
