| 概念 | 我的理解 | 最小例子 |
|---|---|---|
| 字符串三种写法 | 单引号 / 双引号 / 三引号 | `'a'`、`"a"`、`"""a"""` |

## 认知修正 ★

1. **我原来以为** `//` 和 `%` 差不多，都是"除法的余数"
   **实际上是**：`//` 是**整除**（求商，向下取整），`%` 是**取模**（求余）。
   `7 // 2` → `3`；`7 % 2` → `1`。
   **验算恒等式**：`a == (a // b) * b + (a % b)` → `-7 == (-4) * 2 + 1` ✅

2. **我原来以为** `-7 // 2` 应该是 `-3`（向零截断，像 C 那样）
   **实际上是**：`-4`。Python 的 `//` 是**向下取整**（往数轴左边走），不是向零截断。

3. **我原来以为** `"ab" * 3` 会报错（类型不同）
   **实际上是**：`ababab`。**`序列 * int` 是重复**，对 str / list / tuple 都成立。
   只有 `+` 要求两边同类型 —— `"ab" + 3` 才报 `TypeError`。

4. **我原来以为** 三引号是用来写"多行注释"的
   **实际上是**：三引号是**多行字符串**，用途是跨行文本（SQL / HTML / 长 prompt）。
   拿它当注释是**利用副作用** —— 字符串表达式单独成句不产生操作，所以不报错，但那个字符串**真的被创建了**。
   **真正的注释只有 `#`。**

5. **我原来以为** `x == y` 比的是"是不是同一个对象"
   **实际上是**：`==` 比**值**（相等），`is` 比**身份**（是不是同一个对象）。
   判据：`a = [1, 2]; b = [1, 2]` → `a == b` 是 `True`，但 `a is b` 是 `False`。
   `id(x) == id(y)` 和 `x is y` 是一回事。

## 容易踩的坑

- **`//` 是整除、`%` 是取模，别搞反**
- **负数整除是向下取整**：`-7 // 2` → `-4`，不是 `-3`
- **`序列 * int` 是重复，不报错**
- **三引号是字符串，不是注释**；真注释只有 `#`
- **`==` 比值、`is` 比身份**：两个内容相同的列表 `==` 是 True，`is` 是 False
