# Python 变量与对象：变量是名字，不是盒子

> 日期：2026-10-__ ｜ 对应课程：黑马程序员《Python+AI 零基础入门到大神》第 1–2 章 ｜ 状态：🟢 已完成

## 一句话总结

Python 的变量不是"装东西的盒子"，而是"贴在对象上的名字"；赋值是让名字指向对象，不是复制对象。这一条解释了后面所有的"改了 a 结果 b 也变了"。

## 核心概念

| 概念 | 我的理解 | 最小例子 |
|---|---|---|
| 对象 | 真正存数据的东西，有类型和 id | `id([1,2])` |
| 变量 | 一个名字，指向某个对象 | `a = [1,2]` 后 `a` 只是标签 |
| 可变 / 不可变 | 能否原地改内容。list/dict/set 可变；int/str/tuple 不可变 | 见下 |
| 赋值 | 让名字指向另一个对象，**不复制** | `b = a` |

## 认知修正 ★

- **我原来以为**：`b = a` 是把 a 的内容复制一份给 b。
- **实际上是**：`b = a` 只是让 `b` 这个新名字指向同一个对象。之后用可变对象做原地修改，两边都会变。
- **为什么容易搞错**：其他语言（如 C）的变量语义更接近"盒子"，直觉会带过来。而且不可变对象（int、str）看起来"复制"了，因为 `a += 1` 其实是新建对象再改指向，不是原地改。

```python
a = [1, 2, 3]
b = a          # 不是复制，是同一个对象多了一个名字
b.append(4)
print(a)       # [1, 2, 3, 4]  ← a 也变了
print(a is b)  # True

x = 1
y = x
y += 1         # int 不可变，这里是"新建 2 并让 y 指向它"
print(x)       # 1  ← x 没变
```

要真正复制，用 `b = a.copy()`（浅拷贝）或 `copy.deepcopy(a)`（嵌套结构用这个）。

## 关键代码

```python
import copy

a = [[1, 2], [3, 4]]

b = a                  # 同一个对象
c = a.copy()           # 浅拷贝：外层新对象，内层还是共享
d = copy.deepcopy(a)   # 深拷贝：完全独立

a[0].append(99)
print(b)   # [[1, 2, 99], [3, 4]]
print(c)   # [[1, 2, 99], [3, 4]]  ← 浅拷贝挡不住嵌套层
print(d)   # [[1, 2], [3, 4]]     ← 深拷贝才独立
```

## 容易踩的坑

- **函数默认参数用可变对象**：`def f(x, acc=[])` —— 默认值只在定义时创建一次，会跨调用累积。正确写法是 `def f(x, acc=None): acc = [] if acc is None else acc`。
- 用 `is` 比较值。`is` 比的是"是不是同一个对象"，比值要用 `==`。小整数和短字符串有缓存会让人误以为 `is` 能用。
