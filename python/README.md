# python/

Python 学习区。**笔记和代码分开放，不混在一起。**

| 目录 | 放什么 | 命名方式 |
|---|---|---|
| `01-basics/` | **笔记**（`.md`）：概念、认知修正、踩过的坑 | 按主题：`notes.md`、`strings-operators.md`、`03_if-while-for.md` |
| `code/` | **练习代码**（`.py`）：能直接跑的东西 | 按顺序编号：`01.py`、`02_strings.py`、`03_if-while-for.py` |

## 五条约定

1. **一个主题一份笔记** —— 同一章可以有多份 `.md`
2. **笔记里不放可运行脚本** —— 代码一律进 `code/`
3. **笔记和代码用同一个编号对得上** —— `03_if-while-for.md` ↔ `03_if-while-for.py`
4. 笔记格式参考 [`../templates/notes.md`](../templates/notes.md)
5. **文件名只用英文字母、数字、下划线、连字符** —— 中文标点（`、` `，`）会让 Markdown 链接和命令行出问题
