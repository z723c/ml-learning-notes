# 踩坑记录

**只记卡超过 15 分钟的问题。** 命名：三位编号 + 一句话描述。

## 写法

目标：**一屏（≤25 行）看完，只看这一条就能复现修复动作。**

| 要写 | 不要写 |
|---|---|
| **现象**：一行，含关键报错字符串（要能被搜到） | 完整报错原文（只留出错那一行） |
| **原因**：一两句机制 | 科普式解释 |
| **解法**：可直接复制的命令 | 参数说明表格 |
| **判据**：容易搞错时才写 | 独立的「验证」章节 |
| **教训**：一句可迁移的话 | 环境背景章节 |

环境信息（Python / torch 版本等）只在**与问题强相关**时写，并压进「现象」或「原因」里一句话带过。

一般错误 10–15 行；版本 / 环境类 20–25 行。**超过 30 行就是在写博客了。**
