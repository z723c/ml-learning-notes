## 阅读顺序建议

1. **先读综述再读方法**：综述建立坐标系，知道有哪些流派和空白，再读具体方法就不迷路。
2. **先读图和摘要，再读方法，最后才看实验**。三遍法：第一遍 5 分钟（标题/摘要/图/结论），第二遍 30 分钟（方法细节，不懂的标记但不查），第三遍 1 小时（补公式与实验，能复述为止）。
3. **读完立刻写笔记**，第二天写等于没读。
4. **每篇必须回答一个问题：它和我的方向有什么关系**（可借鉴 / 可改进 / 可作 baseline）。
